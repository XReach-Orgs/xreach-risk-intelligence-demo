# XReach Risk Intelligence Demo Platform

Production-style MLOps and Platform Engineering demo targeting Azure Kubernetes Service (AKS).

## Stack

- Frontend: React + Vite
- Backend: FastAPI + PostgreSQL
- ML: scikit-learn + MLflow
- Platform: Docker + AKS + ACR + Terraform
- Observability: Prometheus + Grafana

## Goals

- Secure ML inference platform
- Production-style CI/CD
- AKS deployment with Terraform
- Observability and operational readiness
